Related Tools
*************

The following tools complement ecFlow and may be useful in workflow management and operations.

**Pyflow**

Pyflow is a Python-based workflow generator for ecFlow. It provides a high-level Python API
for building ecFlow suites programmatically. Source code and documentation are available at:

* `GitHub: ecmwf/pyflow <https://github.com/ecmwf/pyflow>`_
* `Pyflow documentation <https://pyflow-workflow-generator.readthedocs.io/en/latest/>`_

**Troika**

Troika is a job submission and management tool for HPC environments, designed to work alongside
workflow managers such as ecFlow. It is available at:

* `GitHub: ecmwf/troika <https://github.com/ecmwf/troika>`_

**ectop**

ectop is a terminal-based monitoring tool for ecFlow servers, inspired by the Unix ``top``
command. It provides a live, text-mode view of suite and node states. It is available at:

* `GitHub: noaa-emc/ectop <https://github.com/noaa-emc/ectop>`_
* `ectop documentation <https://noaa-emc.github.io/ectop/>`_
